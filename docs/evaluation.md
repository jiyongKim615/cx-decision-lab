# 평가와 실패 사례

```bash
make lab
```

Python 3.12에서 57개 `unittest` 회귀 테스트를 실행합니다. 이어서 `scripts/evaluate.py`가 정상·실패 시나리오의 기대 상태를 검사하고 `artifacts/evaluation.json`에 실측 결과를 기록합니다. 저장소의 `examples/evaluation.json`은 같은 명령으로 생성한 요약입니다.

| 영역 | 검사하는 경계 |
| --- | --- |
| 분류 | 보정 분위수 경계, 비유한 점수, 누락, ID 중복, 시점 역전, 모델·분류 버전 불일치 |
| 검토 | 위험 항목 우선순위, 제한된 검토 용량, 대기열, 수동 모드 |
| NPS | 응답·초대·모집단 카운트, 분해 항등식, 빈 집단, 기준 모집단 버전 변경 |
| 실험 | 배정 위조, SRM, 모집단 누락, 결과 누락, 종료 이전, 사후 변수, 오류율 |
| 보존 | 내용 해시 재현성, 같은 내용 재저장, 충돌 거부 |

평가 스크립트는 자동 초안 2건 중 1건이 틀리는 경우도 정상적으로 기록합니다. 이는 성공률을 높게 보이게 만들기 위한 테스트가 아니라, 자동 초안과 사람 검토의 경계를 관찰하는 실험입니다.

기본 실험 400건은 양 군에 200건씩 배정됩니다. 결과 1건을 제거하면 효과는 `null`이 됩니다. 처리군 관측을 일부 제거하면 배정 누락과 SRM 등의 사유를 함께 남깁니다. 종료 이전에는 효과를 읽지 않습니다.

테스트 통과는 이 입력 계약과 고정 시나리오의 동작 확인입니다. 통계적 전제의 현실 적합성, 운영 성능, 대규모 데이터 품질을 검증한 결과는 아닙니다.
